# 📊 Statistics & Probability for Data Analytics

## 📌 About This Repository

This repository contains my learning notes, Python implementations, and practice exercises on **Statistics and Probability for Data Analytics**. It focuses on understanding data, identifying patterns, and making data-driven decisions.

## 📚 Topics Covered

- 📊 **Descriptive Statistics:** Mean, Median, Mode, Variance, Standard Deviation, Quartiles, and Outliers.
- 🎲 **Probability:** Basic Rules, Conditional Probability, Bayes' Theorem, Permutations, and Combinations.
- 📈 **Probability Distributions:** Normal, Binomial, Poisson, and Uniform Distributions.
- 🔬 **Inferential Statistics:** Sampling, CLT, Confidence Intervals, and Hypothesis Testing.
- 🔗 **Correlation & Regression:** Covariance, Correlation, and Linear Regression.
- 🐍 **Python for Statistics:** Statistics, NumPy, Pandas, and Data Visualization.

## 🛠️ Tools & Technologies

`Python` • `NumPy` • `Pandas` • `Matplotlib` • `Seaborn` • `Jupyter Notebook` • `Git & GitHub`
